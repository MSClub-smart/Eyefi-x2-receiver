# EyeFiReceiver — Eye-Fi X2 로컬 수신기 (커스텀·독립형)

**Made by Minsik Choi** — 문의·업데이트 요청: msclub@naver.com / 카카오톡 ID: msclub77

공식 앱/레지스트리/클라우드 없이 Eye-Fi X2 카드의 사진을 로컬 폴더로 받는다.
Python 표준 라이브러리만 사용(외부 의존성 0). 프로토콜은 dnSpy 해독 결과 기반.

## 구성
- `eyefi_protocol.py` — credential·무결성다이제스트·SOAP·multipart·tar 처리(핵심)
- `eyefi_server.py`   — TCP 59278 HTTP 서버 + 스트리밍 스풀(이어받기) + 미전송 워치독
- `config.py`         — 카드/폴더/Wi-Fi 기본값 설정(JSON, `cards.json`)
- `gui.py`            — Tkinter 설정·모니터 창(서버·카드관리·전송로그·카드 Wi-Fi·알림 팝업)
- `card_wifi.py` + `EyeFiCardWifi.ps1` — 카드 Wi-Fi 조회/테스트/등록/삭제(클라우드 불필요)
- `__main__.py`       — 실행 진입점(GUI/콘솔)
- `tests/`            — 오프라인 통합테스트(가짜 카드 업로드→저장 검증)

## 실행
- **창 모드**(관리/조회): `Start-EyeFiReceiver.cmd` 더블클릭 — 창 닫으면 종료.
- **트레이 모드**(상주, 데일리용): `Start-EyeFiReceiver-Tray.cmd` 더블클릭 — 창 숨김+서버 자동시작,
  트레이 아이콘 더블클릭으로 창 열기, 창 닫으면 트레이로 숨김. 우클릭 메뉴: 설정열기/서버시작·중지/자동시작/종료.
- **부팅 자동시작**: 창 상단 "부팅 시 자동시작" 체크(또는 트레이 메뉴). HKCU\...\Run 에 등록,
  `pythonw run_tray.pyw`(트레이 모드)로 조용히 기동. 해제도 체크 해제 한 번.
```
cd "C:/EyeFiReceiver"
python -m EyeFiReceiver           # 창 모드
python -m EyeFiReceiver --tray    # 트레이 상주
python -m EyeFiReceiver --headless --port 59279   # 콘솔(실카드 테스트, 공식앱과 공존)
python -m unittest EyeFiReceiver.tests.test_protocol -v   # 테스트
```
> ⚠️ 우리 수신기와 공식 EyeFiX2Receiver 는 **동시에 59278 을 못 씀**. 데일리로 전환하려면
> 공식앱 종료 + 공식 자동시작(값 'Eye-FiX2') 해제 → 우리 자동시작 켜기. (아래 전환절차)

## 공식 앱에서 실제 전환(cutover) — 유지보수 시간에
1. 트레이의 공식 `EyeFiX2Receiver` 완전 종료(포트 59278 해제).
2. `python -m EyeFiReceiver` 로 이 수신기를 59278 로 시작.
3. 카메라로 1~2장 촬영 → GUI 전송로그에 도착 확인.
   - credential 검증 로그(`cred_ok`)로 카드→서버 인증 공식 확정.
4. 문제 시 이 수신기 종료 후 공식 앱 재실행하면 즉시 원복(설정 안 건드림).

## GUI 툴바 버튼 (등록 카드 목록 위)
- **🔑 카드를 앱에 등록** — 리더의 카드에서 열쇠(업로드키)+MAC 을 읽어 프로그램에 등록(카드엔 안 씀).
  새 카드·기존 카드 공통. 클라우드 불필요.
- **📶 카드 Wi-Fi** — 카드 칩에 Wi-Fi(SSID+비번) 써넣기. 조회/테스트/등록/삭제. (유일하게 카드에 쓰는 버튼)
- **💾 리더에서 가져오기** — 카드 DCIM 사진을 폴더로 직접 복사(촬영일 분류, 중복 스킵). Wi-Fi 대신 리더로 회수.
- **수정 / 삭제** — 프로그램에 등록된 카드 목록 관리(칩 안 건드림).

## 데일리 전환 절차 (유지보수 시간에, 되돌리기 가능)
1. 우리 앱: 창 상단 "부팅 시 자동시작" 체크(또는 트레이 메뉴).
2. 공식앱 자동시작 해제: PowerShell
   `Remove-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name 'Eye-FiX2'`
3. 공식앱 종료: `Stop-Process -Name EyeFiX2Receiver -Force`
4. 우리 앱 트레이 실행: `Start-EyeFiReceiver-Tray.cmd` (서버 자동시작, 59278 확보).
5. 며칠 사용해 문제 없으면 유지. 되돌리려면 우리 자동시작 해제 + 공식 자동시작 복원(값 'Eye-FiX2'
   = `C:\Program Files (x86)\Eye-Fi\EyeFiX2Receiver.exe`).
